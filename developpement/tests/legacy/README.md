# Contrôles historiques de la v1

Le mode Couleurs a été retiré à la demande de l’utilisateur. Ses anciens calculs et contrôles sont conservés ici pour mémoire et ne sont pas inclus dans le HTML ni dans les suites actives de la version actuelle. Les quatre anciens tests de palette encore présents à la racine des tests utilisent ces références historiques. Les résultats v1 sont conservés dans validation/v1. Les tests de la palette Sonorités restent actifs.
